The most playful way to watch your Grok Bots work.

Pixel GrokBots turns named Grok Bot teammates and Grok Build sessions into animated characters on a tiny night-shift office floor. They walk to desks, type when they edit, read when they search, hand work across the room, and raise a flag when an approval gate fires. The glowing rack in the middle is the shared cloud computer.

One bot, one character.

The office is a visualization layer, not another chat window. Activity on the floor is meant to map onto real Grok Bot and Grok Build events.

Live activity

Typing, reading, browsing, and command-running each get their own animation so you can read the room without opening every thread.

Approval bubbles

When a bot hits a gate — send, publish, buy, delete — it stops and raises a red flag instead of disappearing into a transcript.

Shared computer

The center rack is the account-scoped cloud VM. Files, sessions, and logins live there. Subagents spawn from it and take a hot desk.

Handoffs

Orbit can walk a brief to Kai. Rex can drop a dossier on Nova’s desk. Group-chat delegation becomes a path across the floor.

Routines

Scheduled jobs walk in like a shift change. A clock spark on the character means a routine just fired.

Ghost shift

Bots still working after you close the laptop render translucent. The floor keeps moving while you are away.

Hook the real agents in.

v0 is a playable office with a simulated hook stream. The next step is a Grok Build provider — the same idea as Pixel Agents’ HookProvider, pointed at grok instead of Claude Code.

Grok Build / Grok Bot event     →   Office motion

SessionStart                    →   spawn / walk to desk
PreToolUse: write | edit        →   sit + type
PreToolUse: read | grep         →   sit + read
PreToolUse: bash | terminal     →   lean into the rack
PermissionRequest / gate        →   red bubble, freeze
SubagentStart                   →   extra character from the VM
BotMessage / handoff            →   walk to peer, talk
RoutineTick                     →   clock spark, new job
Stop / idle                     →   sit back, look at the window
